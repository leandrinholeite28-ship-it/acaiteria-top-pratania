# Açaiteria Top Sorveteria

Site de cardápio da Açaiteria Top Sorveteria, em Pratânia - SP.

## Como abrir no Visual Studio Code

1. Descompacte o arquivo ZIP.
2. Abra o Visual Studio Code.
3. Clique em **Arquivo > Abrir Pasta** e escolha a pasta `acaiteria-top-site`.
4. Abra o terminal do Visual Studio Code.
5. Execute `npm install` apenas na primeira vez.
6. Depois execute `npm run dev`.
7. Abra no navegador o endereço mostrado no terminal, normalmente `http://localhost:3000`.

## Onde fazer alterações

- Produtos, preços e textos: `app/page.tsx`
- Cores e aparência: `app/globals.css`
- Logo e fotos: pasta `public`
